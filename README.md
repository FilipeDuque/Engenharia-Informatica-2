- Descrição do Projeto:
O utilizador cola um texto ou PDF, a app extrai os conceitos e gera um quiz de escolhas múltiplas.
O uso de IA vem da sumarização e extração da informação dada e a formulação de perguntas.
Este projeto visa, principalmente, auxiliar alunos no treino e preparação para frequências e/ou exames.
